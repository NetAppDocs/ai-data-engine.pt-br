= Avalie a integridade do storage com o painel do AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de decidir o que investigar, você precisa entender o estado do seu storage. Quanto do storage atende aos limites de classificação de dados frios e obsoletos da sua organização, e quais sistemas ou proprietários detêm a maior quantidade de dados nessas categorias? Por exemplo, um administrador de storage que responde a um alerta de capacidade pode ver que uma grande parte do storage verificado contém dados frios e, em seguida, detalhar o sistema de maior impacto para começar a investigar imediatamente.

No NetApp Console, selecione *Governança* > *AI Data Engine UI*. O painel é aberto por padrão.



[[understand-how-much-storage-is-affected]]
== Entenda quanto armazenamento é afetado

O painel de resumo mostra a dimensão do problema em todo o ambiente analisado:

* *Dados frios*: storage não acessado dentro do limite de dados frios (padrão: um ano). Sua organização pode avaliar esses dados de acordo com suas políticas de retenção e governança.
* *Dados obsoletos*: storage que não foi acessado nem modificado dentro do limite de dados obsoletos (padrão: três anos). Os dados obsoletos podem exigir revisão de acordo com as políticas de ciclo de vida dos dados da sua organização antes de decidir sobre ações como arquivamento ou exclusão.
* *Diretórios expostos*: diretórios com configurações de acesso excessivamente permissivas. Esses representam um risco de governança independente do consumo de armazenamento.
* *Recursos de dados*: a quantidade de volumes, compartilhamentos e buckets atualmente analisados.
* *Total de arquivos verificados*: o número total de arquivos indexados em todos os recursos de dados verificados.


Os limites para dados frios e obsoletos refletem suas configurações e podem ser alterados em *Configuração* > *Configurações*. Os valores padrão são os padrões do produto e não representam períodos de retenção legais, de conformidade ou padrão do setor. Consulte link:../administer/configure-settings.html["Configure os limites para dados frios e obsoletos"].

O gráfico _Storage ativo versus recuperável_ mostra a proporção de dados ativos em comparação com dados frios e obsoletos em todos os recursos analisados. Uma alta proporção de dados frios, obsoletos ou duplicados pode indicar uma oportunidade significativa de otimização de storage.

Os filtros *Sistema* e *Tipo de sistema* controlam o escopo do painel. Se um sistema de storage não aparecer na lista de filtros, consulte link:../data-sources/connect-data-source.html["Conecte uma fonte de dados"].



[[identify-storage-optimization-opportunities]]
== Identificar oportunidades de otimização de armazenamento

Use o painel de resumo e o gráfico para identificar e priorizar oportunidades de otimização de armazenamento:

* Priorize os recursos que têm o maior tamanho potencialmente recuperável, em vez daqueles com o maior tamanho total. Um sistema pequeno, composto principalmente por dados inativos ou obsoletos, pode ser um recurso melhor para você avaliar primeiro do que um sistema grande e predominantemente ativo.
* Procure grandes concentrações de dados frios ou obsoletos em vez de arquivos isolados. Dezenas de terabytes de dados que atendam ao seu limite de obsolescência em um único recurso justificam uma avaliação; arquivos isolados podem não exigir nenhuma ação.




[[move-from-the-dashboard-to-investigation]]
== Passe do painel de controle para a investigação

Quando você identificar um recurso ou proprietário que valha a pena investigar, use as tabelas na parte inferior do painel para acessar diretamente os detalhes.

A tabela _Principais recursos de dados por storage recuperável_ lista seus recursos de storage verificados, classificados pela proporção de dados duplicados ou que atendem aos limites de dados inativos e obsoletos da sua organização. Selecione qualquer linha para abrir a visualização Investigation filtrada para esse recurso. A partir daí, use a guia link:investigate-unstructured.html["Não estruturado"] para identificar arquivos inativos ou obsoletos, ou a guia link:investigate-directories.html["Diretórios"] para auditar a exposição de permissões.

A tabela _Principais proprietários de dados por armazenamento recuperável_ mostra quais proprietários de dados possuem dados potencialmente recuperáveis. Selecione qualquer linha para abrir a visualização link:investigate-unstructured.html["Investigação"] filtrada para os arquivos desse proprietário. A partir daí, você pode revisar os resultados, agir com base neles ou salvá-los como uma política.
