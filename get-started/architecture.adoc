= Arquitetura do AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O AI Data Engine (AIDE) consiste em um Metadata Engine e uma estrutura de políticas. Esses recursos trabalham em conjunto para extrair metadados dos seus sistemas de storage, catalogá-los em um índice pesquisável e permitir que você defina consultas salvas para identificar e agir sobre arquivos que correspondam a critérios específicos.



[[components]]
== Componentes

Você interage principalmente com o AI Data Engine por meio de quatro áreas funcionais: o painel, a investigação, as políticas e a configuração. Essas áreas funcionais são alimentadas pelos seguintes componentes subjacentes.



[[metadata-engine]]
=== Metadata Engine

O Metadata Engine é o principal recurso do AI Data Engine. Ele verifica os sistemas de storage conectados para extrair metadados do sistema de arquivos e armazena esses metadados em um catálogo pesquisável. O Metadata Engine atualiza o catálogo a cada ciclo de varredura, detectando adições, alterações e exclusões em seus sistemas de storage.



[[netapp-console-agent]]
=== Agente do NetApp Console

O AI Data Engine requer um Agente de Console NetApp implantado em seu ambiente. O Agente de Console é um componente de plataforma NetApp de uso geral que mantém a conectividade entre seu ambiente local e o NetApp Console. Ele gerencia a autenticação e a comunicação entre seu site e o serviço AIDE.


NOTE: O Agente de Console não é específico do AI Data Engine. Se você já tiver um Agente de Console implantado para outros serviços da NetApp, poderá usar o mesmo agente. Para obter instruções de implantação do Agente de Console, consulte a link:https://docs.netapp.com/us-en/console-setup-admin/concept-agents.html["Documentação do agente do NetApp Console"].



[[deployment-models]]
== Modelos de implantação

O AI Data Engine suporta dois modelos de implantação:

O AIDE Lite:: Implantação em uma única máquina virtual, ideal para ambientes menores. Disponível nas configurações Small, Medium e Large, com base no número de arquivos a serem catalogados.
O AIDE Enterprise:: Implantação de cluster com vários nós baseada em Kubernetes para ambientes maiores que exigem alta disponibilidade.


O AIDE Enterprise tem escalabilidade desde uma configuração de três nós que suporta até aproximadamente um bilhão de arquivos e 250 milhões de arquivos por dia até uma configuração de nove nós que suporta até aproximadamente seis bilhões de arquivos e dois bilhões de arquivos por dia. Consulte link:../deploy/aide-requirements.html["Requisitos do AIDE"] para obter detalhes sobre o dimensionamento dos nós. Nós adicionais podem expandir a capacidade para além de seis bilhões de arquivos. Consulte link:../deploy/aide-requirements.html#flexible-sizing-enterprise["diretrizes flexíveis de dimensionamento"] para obter detalhes sobre a escalabilidade horizontal.

[[data-flow]]
== Fluxo de dados

. O AI Data Engine é implantado no seu ambiente local.
. Você adiciona os sistemas de armazenamento que deseja que o AIDE catalogue em *Configuração > Sistemas*. Os sistemas compatíveis incluem o NetApp ONTAP, o StorageGRID, sistemas de banco de dados e qualquer sistema NAS ou de storage de objetos que exponha os protocolos NFS, SMB/CIFS ou S3.
. O Metadata Engine monta compartilhamentos usando os protocolos NFS e SMB/CIFS e examina os sistemas de arquivos para extrair metadados de arquivos.
. Os metadados são indexados no catálogo.
. O painel exibe insights de storage do catálogo.
. A função Investigation permite consultar diretamente o catálogo com filtros de metadados.
. Você pode salvar critérios de pesquisa como políticas e executá-las novamente para identificar e agir sobre os arquivos correspondentes.



NOTE: Após o Metadata Engine concluir a verificação de todos os volumes configurados, ele inicia imediatamente uma nova rodada de verificação, analisando novamente os sistemas de arquivos para detectar adições, alterações e exclusões.
