= Guia rápido para AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Coloque o AI Data Engine (AIDE) em funcionamento implantando o serviço, conectando suas fontes de dados e iniciando sua primeira investigação. Você também pode permitir que clientes de IA pesquisem seus metadados por meio de acesso governado à IA.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Um"] link:../deploy/aide-requirements.html["Analise os requisitos e selecione um tipo de implantação"]
[role="quick-margin-para"]
Analise os requisitos e link:../deploy/deployment-overview.html["saiba mais sobre os tipos de implantação"]decida se deve instalar uma implantação de nó único ou multinó do AIDE.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dois"] link:../deploy/deployment-overview.html["Implantar o AI Data Engine"]
[role="quick-margin-para"]
Implante um link:../deploy/deploy-aide-single-node.html["Implantação de nó único do AIDE"] ou um link:../deploy/deploy-aide-multi-node.html["Implantação multinó do AIDE"] do NetApp Console. A página de configuração orienta você na seleção do local de instalação e do tamanho da configuração, além da execução do comando de instalação. Se o seu host ou cluster acessar a internet somente por meio de um proxy, use link:../deploy/configure-proxy.html["implantar com um proxy"] em vez disso.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Três"] link:../data-sources/connect-data-source.html["Conecte uma fonte de dados"]
[role="quick-margin-para"]
Conecte uma fonte de dados para iniciar a varredura. O AI Data Engine cataloga os metadados das fontes de dados que você conecta.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatro"] link:../investigate/understand-dashboard.html["Explore seus dados"]
[role="quick-margin-para"]
Abra o painel para ver informações sobre otimização de armazenamento ou acesse link:../investigate/investigate-data.html["Investigação"] para pesquisar e filtrar seus metadados diretamente.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinco"] link:../policies/create-policy.html["Criar uma política"]
[role="quick-margin-para"]
Salve seus filtros de investigação como uma política para monitorar arquivos que correspondam aos mesmos critérios ao longo do tempo. Você pode configurar uma política para enviar uma notificação, excluir permanentemente os arquivos correspondentes ou rastrear os resultados.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Seis"] link:../mcp/quick-start-mcp.html["Opcional: configurar o acesso governado à IA"]
[role="quick-margin-para"]
Permita que os clientes de IA pesquisem os metadados nas coleções que você escolher. Usuários avançados podem pesquisar metadados e realizar ações com os dados.
