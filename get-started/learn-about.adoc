= Saiba mais sobre AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O AI Data Engine (AIDE) é um serviço de inteligência de metadados que oferece visibilidade dos dados estruturados e não estruturados armazenados em seus sistemas de storage. O AI Data Engine examina seus sistemas de storage e cataloga os metadados do sistema de arquivos para que você possa identificar oportunidades de otimização de storage, investigar seus dados e impor políticas de governança.



[[what-ai-data-engine-does]]
== O que o AI Data Engine faz

O AI Data Engine analisa as fontes de dados que você conecta e cria um catálogo de metadados pesquisável, que é atualizado a cada ciclo de análise. A partir desse catálogo, você pode:

* *Entenda seu armazenamento.* Veja a quantidade de dados que você tem, quem os possui e onde estão armazenados.
* *Recupere capacidade.* Encontre dados frios, obsoletos e duplicados e veja quais proprietários dos dados detêm a maior parte deles, para que você saiba com quem entrar em contato para a limpeza.
* *Identifique riscos de acesso.* Identifique diretórios com permissões abertas para que você possa priorizá-los na revisão.
* *Investigue e organize.* Use filtros de metadados para encontrar os dados que interessam a você, etiquete-os e salve seus critérios como uma política que você poderá monitorar ao longo do tempo.
* *Aja com base nos dados.* Marque, arquive, copie ou exclua os arquivos que você revisou.
* *Prepare os dados para IA.* Permita que os clientes de IA que você autorizou pesquisem seus metadados e realizem ações com base nos dados.




[[storage-optimization-and-data-lifecycle-management]]
== Otimização de armazenamento e gerenciamento do ciclo de vida dos dados

Use metadados para identificar dados que justificam revisão, como arquivos que atendem aos limites de dados frios e obsoletos da sua organização e arquivos duplicados. Analise os resultados antes de decidir se deve manter, etiquetar, arquivar, copiar ou excluir os dados.

As informações sobre otimização de armazenamento apontam para oportunidades. A capacidade que você poderá recuperar depende das ações que escolher tomar.



[[governed-ai-access]]
== Acesso controlado à IA

O acesso controlado de IA permite que clientes de IA pesquisem seus metadados por meio do Model Context Protocol (MCP), dentro dos limites que você define. Você escolhe quais dados disponibilizar criando coleções. Uma coleção é um conjunto de dados escaneados que você disponibiliza para clientes de IA. Você controla quais coleções um usuário pode pesquisar definindo os escopos do Microsoft Entra ID.

Os clientes de IA trabalham apenas com metadados. Eles não conseguem recuperar o conteúdo dos arquivos.

link:../mcp/learn-about-mcp.html["Saiba mais sobre o acesso governado à IA"].



[[who-uses-ai-data-engine]]
== Quem usa AI Data Engine

Os exemplos a seguir mostram como diferentes pessoas podem usar o AI Data Engine:

* *Administradores de armazenamento* que precisam revisar arquivos que atendem aos limites de inatividade e obsolescência da sua organização, identificar arquivos duplicados e avaliar oportunidades de otimização de armazenamento.
* *Equipes de operações de TI* que precisam de uma visão centralizada dos dados estruturados e não estruturados existentes em seu ambiente de storage.
* *Membros da equipe de dados ou de IA* que usam um cliente de IA para pesquisar os metadados em uma coleção autorizada e marcar os dados com os quais desejam trabalhar.
* *Líderes de TI* que estão implementando ferramentas de IA e precisam escolher em quais coleções os clientes de IA podem pesquisar e quem pode usá-las.




[[where-ai-data-engine-runs]]
== Onde o AI Data Engine é executado

Você acessa o AI Data Engine pelo NetApp Console, em *AI data hub > AI Data Engine*. Os serviços de varredura e catalogação são executados na infraestrutura que você fornece, seja na sua conta na nuvem ou no seu ambiente local. Escolha uma implantação de nó único do AIDE em uma VM Linux ou uma implantação de vários nós do AIDE em um cluster Kubernetes se o seu ambiente exigir alta disponibilidade em grande escala.

link:../deploy/deployment-overview.html["Saiba mais sobre as opções de implantação"].

O AI Data Engine analisa as fontes de dados compatíveis que você conecta. Para obter mais informações, consulte link:../data-sources/connect-data-source.html["Conecte uma fonte de dados"].
