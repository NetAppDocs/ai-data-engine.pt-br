= Implantar o AI Data Engine Enterprise
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Implante o AIDE Enterprise a partir do NetApp Console usando o assistente de implantação. O assistente orienta você na seleção do seu local de instalação, na escolha de um tamanho de configuração e na execução do comando de instalação no seu cluster RKE2.

.Antes de começar
* Você tem permissões de _Administrador da organização_ ou superiores no NetApp Console.
* Seu cluster RKE2 atende aos pré-requisitos do nó Enterprise descritos em link:aide-requirements.html["Requisitos do AIDE"].
* São necessárias permissões de sudo (ou root) na máquina a partir da qual você executa o comando de instalação.
* Um servidor NFS com um caminho exportado está disponível e acessível a partir do cluster para o volume de configuração do AIDE.
* Um agente da NetApp Console https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html#agent-console-deploy["é implantado"^] acessível a partir dos nós do cluster. O endereço IP do Console Agent é necessário para executar o comando de instalação.
* O kubectl está disponível na máquina a partir da qual você executa o comando de instalação, com acesso de administrador de cluster ao cluster de destino.
* O namespace Kubernetes de destino (padrão `aide`) já existe no cluster antes de você executar o comando de instalação.
* Uma StorageClass configurada (nome padrão: `aide-sc`) está disponível no cluster e é usada para os serviços de suporte com estado do AIDE.


.Passos
. No NetApp Console, navegue até *Governança* > *AI Data Engine*.
+
A página inicial do AI Data Engine é exibida.

. Selecione *Implantar o AI Data Engine*.
. Selecione a opção de implantação *Enterprise* e selecione *Avançar*.
. Copie o comando de instalação pré-configurado exibido no assistente para um editor.
. Selecione o tamanho da sua configuração:
+
** *Pequeno*: recomendado para ambientes com até aproximadamente 1 bilhão de arquivos.
** *Médio (Padrão)*: recomendado para ambientes com até aproximadamente 3 bilhões de arquivos.
** *Grande*: recomendado para ambientes com até aproximadamente 6 bilhões de arquivos.
+
Esses tamanhos são valores de referência recomendados, não limites rígidos. O AIDE Enterprise oferece suporte a ambientes com mais de 6 bilhões de arquivos por meio de escalabilidade horizontal; consulte link:aide-requirements.html#flexible-sizing-enterprise["diretrizes flexíveis de dimensionamento"] para obter detalhes.



. Para configurações pequenas ou grandes, ajuste o comando de instalação de acordo com o tamanho escolhido: `--flavor <small|medium|large>`
. Execute o comando de instalação com quaisquer ajustes de tamanho da configuração no seu host de destino com acesso kubectl ao seu cluster RKE2.
+

NOTE: A instalação leva cerca de 30 minutos para ser concluída. Podem ocorrer tempos limite e novas tentativas, o que é normal.

. Quando solicitado, confirme o endereço IP do host e o ID do usuário para continuar a instalação.
. Acompanhe a tela de progresso até que a tela de sucesso apareça e exiba "AI Data Engine implantado".


.Resultado
O AI Data Engine Enterprise foi implantado e conectado ao NetApp Console. Agora você pode link:../data-sources/connect-data-source.html["conectar uma fonte de dados"] para iniciar a digitalização.
